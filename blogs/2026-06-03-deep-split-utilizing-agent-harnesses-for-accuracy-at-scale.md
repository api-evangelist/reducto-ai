Reducto announced improvements to its Split feature that uses an agent harness architecture to automatically categorize and separate document pages into relevant sections. The enhanced tool can handle documents with thousands of pages and 150+ categories while providing contextual evidence for each page assignment. These improvements enable faster, more accurate downstream extraction by ensuring cleaner data context and proper document routing.
